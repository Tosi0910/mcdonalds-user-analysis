# 麦当劳用户感知与细分人群分析

基于 1453 份问卷数据，使用 Spearman 相关分析、PCA 降维与 K-Means 聚类，识别影响用户喜爱度的关键因素，并将用户划分为 5 类细分人群，输出差异化营销策略。

---

## 项目背景

快餐行业竞争加剧，麦当劳面临三大挑战：

1. **品牌认知固化**：消费者对快餐存在“高热量、不健康”的刻板印象，部分客群认为性价比不足；
2. **客群需求分化**：年轻群体注重口味与体验，中年群体更关注健康与营养；
3. **营销资源有限**：预算受限下，如何实现“千人千面”的精准投放？

本项目希望回答三个业务问题：

- **归因**：哪些感知因素最影响用户对麦当劳的喜爱程度？
- **分群**：用户可以分成哪几类？每类人群的核心特征是什么？
- **策略**：针对不同人群，营销资源应如何差异化分配？

---

## 数据来源

- **来源**：[Kaggle - McDonald's Market Segmentation Dataset](https://www.kaggle.com/datasets/pamalkrmondal/mcdonalds-market-segmentation-dataset)
- **样本量**：1453 份有效问卷
- **字段**：
  - 11 个二元感知变量（yummy、convenient、spicy、fattening、greasy、fast、cheap、tasty、expensive、healthy、disgusting）
  - Like：整体喜爱度（-5 ~ +5）
  - Age / Gender：人口统计变量
  - VisitFrequency：光顾频率（Never ~ More than once a week）

## 项目流程

### 1. 数据预处理

| 操作 | 做法 | 为什么 |
|---|---|---|
| 数据检查 | 确认无缺失值、重复值、异常值 | 保证建模输入干净 |
| Like 字段清洗 | 从 "I love it!+5" 提取数值 → `like_int` | 文本无法参与相关分析与聚类 |
| 感知变量二元化 | 11 个 Yes/No → 0/1（`_bin`） | 相关分析与距离聚类需要数值化 |
| 光顾频率有序编码 | VisitFrequency → 0–5 `freq_code` | 保留“从不光顾 → 每周多次”的顺序信息 |
| 标准化 | StandardScaler | K-Means 基于欧氏距离，量纲不同会导致聚类偏斜 |

### 2. 探索性分析（EDA）

- 样本性别均衡（女 788 / 男 665），年龄 18–71 岁分布均匀；
- 喜爱度偏正面，正分人群远高于负分人群；
- 光顾频率集中在“每三个月一次”至“每月一次”，中低频为主；
- 认可度前三：convenient、fast、fattening；
- 否认度前三：spicy、healthy、disgusting。

### 3. 归因分析

将 11 个感知变量分为三组，Spearman 相关分析结果：

| 感知组 | 代表变量 | 相关系数 | 影响强度 |
|---|---|---|---|
| 口味组 | yummy、tasty、disgusting | 0.692、0.628、-0.530 | 最强 |
| 健康组 | healthy、fattening | 0.296、-0.174 | 中等 |
| 便捷组 | convenient、fast、cheap | 0.316、0.160、0.147 | 最弱 |

**核心结论**：口味是第一驱动因素，健康次之，便捷/实惠仅是加分项。

### 4. 用户聚类

- **PCA 降维**：前 5 个主成分累计方差贡献率 71%；
- **K 值选择**：肘部法则（K=5 后 SSE 下降趋缓）+ 轮廓系数（K=5 为 0.315，较高水平）；
- **K-Means 聚类**：最终 K=5，得到 5 类差异显著的人群。

## 策略建议

**核心逻辑**：营销资源按“口味 > 健康 > 便捷/价格”配置，优先打“体量大、转化路径短”的人群。

### P0：Cluster 4 健康顾虑型（29.7%）

- **目标**：消除“不健康”顾虑，转化为下一批忠实顾客。
- **动作**：推出“轻负担”系列，菜单标注卡路里；投放健身/轻食/白领 KOL；App 推送轻负担套餐。
- **指标**：轻负担系列销量占比、月均到店频次（目标提升 10%–15%）。
- **风险**：不能因强调健康而弱化口味；健康沟通要真实。

### P0：Cluster 2 忠实顾客型（15.2%）

- **目标**：守住核心资产，提升复购与客单价。
- **动作**：会员等级与积分加速；新品优先试吃；推荐有礼，转化为 KOC。
- **指标**：月均到店频次、客单价、留存率、推荐率（目标频次提升 15%–20%）。
- **风险**：避免过度打扰与会员权益“通胀”。

### P1：Cluster 0 价格顾虑型（24.1%）

- **目标**：降低价格门槛，提升到店频率。
- **动作**：1+1 随心配、工作日午餐特惠、满减券；推出超值套餐。
- **指标**：月均到店频次、优惠券使用率、套餐销量（目标频次提升 15%–20%）。
- **风险**：过度促销损害品牌价值；避免吸引“只买促销品”的用户。

### P2：Cluster 1 被动消费型（19.3%）

- **目标**：扭转口味负面认知，从被动消费转为主动选择。
- **动作**：主打“美味、口感”；抖音/小红书 KOL 种草；门店试吃。
- **指标**：月均到店频次、喜爱度变化、试吃转化率（目标喜爱度由负转正）。
- **风险**：口味扭转难度大，需持续投入。

### P2：Cluster 3 流失型（11.7%）

- **目标**：低成本唤醒 5%–10% 的流失用户，观察反馈。
- **动作**：大额优惠券、免费小食试吃；沟通主题“我们变了，来试试”。
- **指标**：优惠券核销率、回店率、喜爱度变化。
- **风险**：挽回成本高，不宜投入过多；若效果差，资源转向高潜力人群。

## 分阶段执行节奏

| 阶段 | 时间 | 重点人群 | 目标 |
|---|---|---|---|
| 第一阶段 | 1–2 个月 | Cluster 0 + Cluster 4 | 快速提升到店频次，验证价格与健康策略 |
| 第二阶段 | 3–4 个月 | Cluster 2 + Cluster 4 | 提升核心用户复购与客单价 |
| 第三阶段 | 5–6 个月 | Cluster 1 + Cluster 3 | 扭转认知，降低流失率 |

## 策略验证思路

本报告策略基于问卷数据推断，尚未经过实验验证。后续可设计：

1. **A/B 测试**：对 Cluster 4 随机分组，一组推送轻负担套餐，一组推送常规套餐，对比 4 周内到店频次与客单价；
2. **对照组设计**：对 Cluster 3 随机选择一半发送大额优惠券，另一半不发送，对比回店率；
3. **长期追踪**：按月追踪各人群喜爱度、光顾频率、客单价变化。
